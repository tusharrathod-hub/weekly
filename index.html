About This Dashboard
What it shows, its features, and how to use it

📊 What it includes

Weekly performance across 6 periods (1–12 Jul → 1–16 Aug) for 32 programs, shown as 8 bar charts: Enrollments, Revenue (₹ Cr/Lakhs), Blended Leads, Search Leads, Meta Leads, L2R %, Search L2R, Meta L2R. Data is sourced from the Weekly Report workbook.

✨ Features

  • Program filter — multi-select tiles
  • Auto-resize charts (no clustering)
  • Collapsible slicer & each chart
  • Floating ☰ nav — jump anywhere
  • Period + value label on every bar
  • Mobile-ready (Android / iOS)

💡 How to use

  • Tap program tiles to filter (one or many)
  • Tap All Programs to reset
  • Use −/+ on a card to collapse it
  • Tap the floating ☰ to open navigation
  • Pick a chart in the drawer to jump to it
  • Hover/tap a bar for exact values
📈 Reading a bar: each bar is one period; the label after it reads "period, value" (e.g. 1-20 Jul, 93). Revenue uses Indian currency (Cr / Lakhs). Needs internet on first load (charts library).
